# Descrição
O Facebook é uma das maiores e mais populares redes sociais virtuais do mundo, lançada em 2004 por Mark Zuckerberg e seus colegas de quarto da Universidade de Harvard. Hoje, a plataforma pertence à Meta Platforms, Inc. e conecta bilhões de pessoas globalmente.

# Público-alvo
O público-alvo principal do Facebook hoje é composto por adultos e um público mais maduro, concentrado fortemente na faixa etária dos 25 aos 34 anos.

# Principais Funcionalidades
As principais funcionalidades do Facebook combinam conexão social, comunidades engajadas e comércio local. Algumas das funcionalidades são:
- Feed de Notícias (News Feed): A página inicial da rede. O algoritmo organiza e exibe publicações de amigos, páginas seguidas e anúncios, incluindo fotos, vídeos, links e textos.
- Páginas (Facebook Pages): Perfis públicos voltados para empresas, marcas, artistas, criadores de conteúdo e organizações. Servem para criar uma base de fãs e veicular anúncios.
- Facebook Marketplace: Uma aba dedicada à compra e venda de produtos novos ou usados diretamente entre usuários da mesma região geográfica.
- Messenger: O sistema de mensagens privadas do Facebook. Funciona como um aplicativo integrado (ou separado no celular) para conversas por texto, chamadas de voz e vídeo com seus amigos.

# Tecnologias utilizadas
A primeira versão criada por Mark Zuckerberg em 2004 utilizava ferramentas básicas de desenvolvimento web, utilizando o ecossistema LAMP (Linux, Apache, MySQL e PHP):
- PHP: Toda a lógica original do sistema foi escrita em PHP puro. Era uma linguagem rápida para criar páginas dinâmicas;
- MySQL: O banco de dados relacional usado para armazenar informações vitais, como perfis, publicações e as conexões de amigos;
- Apache: O servidor web padrão que rodava os scripts em PHP;
- HTML, CSS e JavaScript: Utilizados para construir a interface visual e permitir interações básicas no navegador do usuário.

# Requisitos para utilização
Para criar uma conta e navegar na plataforma, você precisa atender a critérios de idade mínima (13 anos), possuir dados básicos de contato, conexão de rede (dados móveis ou Wi-Fi) e um dispositivo compatível como:
Computadores (Web): Qualquer navegador de internet atualizado (Google Chrome, Safari, Mozilla Firefox, Microsoft Edge) rodando em Windows, macOS ou Linux;
Celulares e Tablets (Aplicativo):
Android e iOS (iPhone/iPad).
